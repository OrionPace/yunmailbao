云邮宝使用说明

云邮宝是一款本地优先的批量邮件发送桌面工具，面向培训通知、会议邀约、名单群发等既要规模、又要保留人工可控性的场景。下面按「准备 → 导入 → 撰写 → 发送 → 续传 → 排查」的顺序说明全部用法，首次使用与每次正式群发前都建议对照核查。

运行模式 本地优先 账号、日志、发送进度均保存在当前电脑

1. 准备发件账号与 SMTP 授权码

在「发件人账号池配置」中按行填写：发件人别名、邮箱地址、SMTP 授权码。授权码不是邮箱登录密码，需在邮箱网页端单独开通生成。

  • QQ 邮箱：网页端 → 设置 → 账号 → 开启「POP3/SMTP 服务」→ 短信验证后获得 16 位授权码；服务器 smtp.qq.com:587。
  • 163 邮箱：网页端 → 设置 → POP3/SMTP/IMAP → 开启 SMTP → 设置「客户端授权密码」；服务器 smtp.163.com:465。
  • 正式群发建议配置 2-5 个账号轮换，系统会按收件人顺序轮流使用，降低单账号短时压力。
  • 点击「+ 继续添加账号」可增加更多发件箱。

2. 导入收件人 Excel

点击或拖拽上传 .xlsx 文件，系统读取表头后显示「姓名列 / 邮箱列」下拉，请分别选中对应列。

数据格式范例（首行必须是表头）：

  • 姓名 | 邮箱
  • 张三 | zhangsan@qq.com
  • 李四 | lisi@163.com
  • 不要使用合并单元格、隐藏行或空表头。
  • 邮箱列必须是有效邮箱，无效或空行会被自动跳过。
  • 未手动选择映射时，默认取第一列为姓名、第二列为邮箱。
  • 示例文件见 tests/fixtures/sample_recipients.xlsx。

3. 编写正文与附件

富文本编辑器默认空白。正文中可使用 <人名> 占位符，发送时自动替换为该收件人的姓名，实现个性化称呼。

  • 支持字体、字号、行距、加粗、对齐、列表、颜色和图片。
  • 支持直接 粘贴微信/网页截图 到正文（内嵌为图片）。
  • 附件建议使用 PDF，便于收件端打开与归档。
  • 「预览」按钮：用示例姓名替换占位符，群发前先看排版效果。
  • 「测试发送」：填入自己的邮箱先收一封，确认排版与占位符替换正常——强烈建议每次群发前必做。

4. 设置发送节奏与防封策略

发送窗口限制每日发件时间段，批次与抖动控制发送速度。冷启动账号务必从保守参数起步。

  • 窗口开始 / 结束：仅在该时段发件，超时自动挂起等待至次日窗口。
  • 每批发送数：发完这么多封后休眠一次（串行发送，并非并行），新账号建议 1，数值越大节奏越紧凑但越易被封。
  • 最小 / 最大抖动（秒）：每批次之间的随机休眠，建议先用 5-15 秒。
  • 单账号单日上限：每个账号每天最多发多少封，达到即自动跳过该账号；全部账号用尽则自动暂停（可续传）。QQ/163 个人邮箱有日发量限制，建议设保守值（如每账号 200~300）。0 表示不限制。
  • 退订信息：勾选后自动添加 List-Unsubscribe 退订头与正文退订说明，降低投诉、提升送达率。
  • 退订 / 黑名单：把退订或不再联系的邮箱逐行填入并保存，发送时自动排除。
  • 疲劳递增：累计发送越多，休眠自动越长；配合多账号轮换、隐形字符盐值等手段尽量规避反垃圾网关。

5. 断点续传（断网 / 关机不怕）

发送过程中，进度会在每发完一封后自动保存到运行目录的 state/checkpoint.json。若期间断网、断电或手动关闭程序：

  • 重新打开云邮宝，主控制台顶部会出现「检测到上次未完成任务」的提示横幅。
  • 点击 「继续发送」：自动跳过已成功投递的邮箱，仅发送剩余部分，不会重复发送。
  • 点击 「放弃并新建」：清除上次进度记录（已发出的邮件不受影响），重新发起全新任务。
  • 断电场景最多只会重发最后一封正在处理的邮件。

6. 监控、待确认与失败重发

右侧控制台实时显示总计划、已送达、失败、待确认四项指标，进度条旁显示预计剩余时间、当前账号与发送速率。

  • 待确认：连接中断导致投递状态未知的邮件（既不算成功也不算失败），续传/重发时会自动重试，避免静默漏发。
  • 失败原因自动分类：地址不存在、收件箱已满、反垃圾拦截、认证失败、连接超时等。
  • 「导出记录」：把失败 + 待确认的邮箱导出为 Excel 清单。
  • 「重发失败/待确认」：一键仅对失败和待确认的收件人再发一次，无需重建任务。
  • 「安全终止」会请求后台停止并关闭 SMTP 连接，进度同时落盘可续传。
  • 完整日志保存在运行目录的 logs/email_app.log。

7. 安全与上线前注意

当前版本面向本地可信环境。部署到公网前，必须补登录鉴权、上传限制、CORS 白名单与操作审计。

  • 请勿用于垃圾邮件、钓鱼、骚扰等违法用途，仅用于正常通知与邀约。
  • 不要将 .env 或真实授权码提交到 Git。
  • Windows 交付版用 build.bat 打包；阿里云部署流程见 docs/deployment-guide.md。
