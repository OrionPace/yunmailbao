云邮宝操作手册

从账号配置、名单导入、正文编写到发送监控的一页式说明。适合首次使用，也适合每次正式发送前做快速核对。

运行模式 本地优先 账号与日志默认保存在当前机器

1. 准备发件账号

在“发件人账号池配置”中填写发件人别名、邮箱地址和 SMTP 授权码。授权码不是邮箱登录密码，建议为每个邮箱单独生成。

  • QQ 邮箱默认使用 smtp.qq.com:587。
  • 163 邮箱默认使用 smtp.163.com:465。
  • 正式发送建议准备 2-5 个账号轮换，降低单账号短时间压力。

2. 导入收件人 Excel

上传 Excel 后，系统会读取表头并显示“姓名列”和“邮箱列”映射。列名包含“姓名 / name / 邮箱 / email”时会自动预选。

  • 不要使用合并单元格、隐藏行或空表头。
  • 邮箱列必须是有效邮箱格式。
  • 未选择映射时，系统会回退到第一列姓名、第二列邮箱。

3. 编写正文与附件

富文本编辑器默认空白，避免把示例机构内容误发。正文中可使用 <人名> 占位符，发送时会替换为 Excel 中对应姓名。

  • 支持字体、字号、加粗、对齐、列表、颜色和图片。
  • 支持直接粘贴截图到正文中。
  • 附件当前建议使用 PDF，便于收件端打开和归档。

4. 设置发送节奏

发送窗口用于限制每日发件时间，批次和抖动用于控制发送速度。对冷启动账号，建议从保守参数开始。

  • 窗口开始/结束：只在允许时段发件。
  • 单批次并发：新账号建议设为 1。
  • 最小/最大抖动：建议先用 5-15 秒观察稳定性。

5. 监控与失败导出

右侧控制台会显示总计划、已送达、失败和队列进度。任务结束后，如存在失败记录，可导出失败清单继续排查。

  • 失败原因会按地址无效、认证失败、反垃圾拦截、连接异常等分类。
  • 安全终止会请求后台停止任务，并关闭 SMTP 连接。
  • 日志文件保存在运行目录的 logs/。

上线前注意

当前产品适合本地可信环境。部署到公网前，必须补登录鉴权、上传限制、CORS 白名单和操作审计。

  • 阿里云部署和域名备案流程见 docs/deployment-guide.md。
  • Windows 交付版使用 build.bat 打包。
  • 不要将 .env 或真实授权码提交到 Git。
